# Hayatın Anlamını Arayan Ama Bulamayan Script

## Bu Repo Nedir?

Bu repository, insanlık tarihinin en büyük sorusuna cevap vermeye çalışan, ancak her seferinde başarısız olan epik bir yazılım eseridir. 

**Ciddiye almayın.** Ama alın. Çünkü hayat böyledir: anlamsız, ama ciddi.

### Özellikler:
- Gerçekten çalışır (Python ile).
- Sonsuza kadar arar, asla bulamaz.
- Rastgele absürt anlamlar üretir.
- Kahve içerken kullanılması tavsiye edilir.
- Hiçbir bilimsel temel yoktur. 

## Nasıl Kullanılır?

```bash
python3 hayat_anlami.py
```

Sonra soruları cevaplayın ve sonsuz arayışın tadını çıkarın.

## Uyarı

Bu script hayatınızı değiştirmez. Sadece zamanınızı yer. Tıpkı diğer her şey gibi.
